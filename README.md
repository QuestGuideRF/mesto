# Место

Интерактивная веб-страница для просмотра и добавления фотографий интересных мест. Пользователи могут редактировать профиль, добавлять новые карточки с изображениями и ставить лайки.

## ✨ Особенности

- Редактирование профиля пользователя (имя, описание, аватар)
- Добавление и удаление карточек с местами
- Просмотр изображений в полноэкранном режиме
- Система лайков
- Валидация форм
- Адаптивная вёрстка для всех устройств
- Работа с REST API сервера

## 🚀 Быстрый старт

### Установка

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Откроется браузер с приложением на `http://localhost:8080`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## 🛠 Использование

### Функциональность

- **Редактирование профиля** — нажмите на кнопку редактирования рядом с именем
- **Изменение аватара** — наведите на аватар и нажмите на появившуюся кнопку
- **Добавление карточки** — нажмите кнопку "+" в профиле
- **Удаление карточки** — нажмите на иконку корзины (только для своих карточек)
- **Лайк** — нажмите на сердечко под изображением
- **Просмотр изображения** — нажмите на карточку для открытия в полном размере

### Закрытие попапов

- Нажатие на крестик
- Клик по затемнённой области
- Нажатие клавиши `Escape`
